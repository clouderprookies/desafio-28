📊 Desafio 28 - Post 05

🎯 Seu gráfico está bonito. Ele mostra a coisa certa?

Este exercício usa o Julius AI para analisar uma operação fictícia de atendimento e testar quais visualizações realmente ajudam a responder perguntas de gestão.

O objetivo vai além de produzir um dashboard. Você deverá conferir cálculos, comparar visuais e explicar o que cada escolha mostra ou esconde.

🧠 Objetivos do exercício

Ao concluir a atividade, você deverá conseguir:

Fazer o perfil inicial de uma base de atendimento.

Formular perguntas antes de escolher o gráfico.

Comparar contagens e taxas corretamente.

Avaliar média, mediana, percentis e dispersão.

Testar mais de uma visualização para a mesma pergunta.

Conferir o código e os cálculos gerados pelo Julius AI.

Separar fatos, interpretações e limitações.

🧪 Sobre os dados

A base contém 720 atendimentos fictícios distribuídos entre abril e junho de 2026.

Os campos incluem:

data, dia, hora e turno;

canal, categoria e motivo;

região, equipe e agente;

tempo da primeira resposta e meta de SLA;

tempo de resolução;

reabertura;

satisfação;

identificadores sintéticos.

Alguns padrões foram inseridos de propósito. O arquivo não contém informações de clientes, funcionários, empresas, projetos ou sistemas reais.

🔐 Antes de começar

Use somente ferramentas, contas e ambientes autorizados pela sua organização.

O Julius informa que arquivos enviados e resultados são armazenados e processados nos Estados Unidos. A empresa também declara que não usa os dados dos clientes para treinar modelos. Essas características não substituem a política interna nem a autorização da organização.

Ao trabalhar com dados reais:

confirme classificação, retenção e local de processamento;

remova nomes, e-mails, telefones, documentos e IDs pessoais;

não inclua informações contratuais, estratégicas ou confidenciais;

use uma base sintética quando não houver autorização formal.

▶️ Como executar

Baixe os dois arquivos Excel.

Mantenha o gabarito fechado.

Envie somente Base_Atendimentos_Post05.xlsx ao Julius AI.

Abra prompt_julius.md e execute o prompt principal.

Analise os cálculos, gráficos e o código apresentado.

Execute o prompt de revisão.

Use criterios_de_conferencia.md para avaliar a entrega.

Abra o gabarito e compare os resultados.

❓ Perguntas do exercício

Quando e por qual canal o volume se concentra?

Quais grupos quebram mais o SLA proporcionalmente?

Onde a reabertura se repete?

Quais categorias têm maior dispersão no tempo de resolução?

Como SLA e reabertura se relacionam com a satisfação?

✅ O que uma boa entrega deve apresentar

painel com até cinco gráficos;

tabela com os indicadores usados;

cálculos, filtros e denominadores verificáveis;

código utilizado em cada análise;

justificativa para cada visual escolhido;

limitações do visual descartado;

achados separados de interpretações;

resumo executivo de até 150 palavras.

🧰 Ferramenta

O Julius AI permite analisar planilhas em linguagem natural, gerar gráficos e consultar o código usado. Recursos, limites e políticas variam conforme o plano.

Outra ferramenta de análise de dados pode ser utilizada, desde que aceite planilhas, gere cálculos verificáveis e esteja autorizada pela organização.
