Prompt de auditoria

Audite a apresentação card por card.

Crie uma tabela com estas colunas:

- card;
- afirmação principal;
- número utilizado;
- localização do número no briefing;
- status: confirmado, interpretação ou pendente;
- correção necessária.

Depois verifique:

1. se algum número foi arredondado de forma enganosa;
2. se contagem foi comparada como se fosse taxa;
3. se correlação foi apresentada como causa;
4. se alguma recomendação ganhou certeza que o briefing não oferece;
5. se há conteúdo demais para uma apresentação de 5 minutos;
6. se o pedido de decisão está explícito no último card.

Corrija somente o que falhar nessa auditoria. Não acrescente dados novos.

🔐 Segurança

Antes de usar dados reais, confirme a política interna e as ferramentas liberadas pela organização. Remova informações pessoais, financeiras, contratuais e estratégicas. Em contas individuais do Gamma, verifique também a configuração de uso de conteúdo para melhoria dos recursos de IA
