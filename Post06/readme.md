🎨 Desafio 28 - Post 06

🎯 Da análise validada ao pitch que pede uma decisão

Este exercício transforma os resultados do Post 05 em uma apresentação executiva de seis cards no Gamma.

O objetivo é aprender a reduzir conteúdo sem perder evidência, separar fato de interpretação e encerrar a apresentação com uma decisão clara.

📂 Arquivos do exercício

📄 Briefing validado

💬 Prompt para o Gamma

🗝️ Gabarito em PowerPoint

✅ Critérios de conferência

📝 Texto final para o LinkedIn

📚 Fontes para o primeiro comentário

🎨 Ilustração em 4K

🖌️ Prompt da ilustração

🧪 Sobre o cenário

O briefing usa a mesma operação fictícia do Post 05. Todos os números são sintéticos e foram criados exclusivamente para fins educacionais.

Nenhum registro pertence a cliente, pessoa, empresa, projeto ou sistema real.

🧠 O que você vai praticar

Definir a decisão antes de escolher o layout.

Organizar uma narrativa executiva em seis cards.

Limitar gráficos às evidências que realmente ajudam.

Preservar números, períodos e denominadores.

Marcar informações ausentes sem inventar respostas.

Auditar o conteúdo depois da geração.

Conferir o arquivo exportado fora da ferramenta.

▶️ Como executar

Leia briefing_validado_post06.md.

Abra o Gamma e escolha a opção de criar a partir de texto ou conteúdo colado.

Cole o briefing e o prompt principal de prompt_gamma.md.

Revise o roteiro dos seis cards antes de autorizar a geração.

Confira números, títulos, gráficos e limitações.

Execute o prompt de auditoria.

Exporte a apresentação para PowerPoint ou PDF.

Abra o arquivo exportado e faça a conferência final.

Compare sua entrega com o gabarito.

✅ Entrega esperada

exatamente seis cards;

apresentação de aproximadamente cinco minutos;

no máximo dois gráficos;

números rastreáveis até o briefing;

recomendação condicionada a um piloto;

pedido de decisão explícito no encerramento.

🔐 Antes de usar dados reais

[!IMPORTANT]
Acesso público ao Gamma não significa autorização para enviar dados da empresa.

consulte a política interna de IA e segurança;

use somente contas e ambientes aprovados;

retire nomes, contatos, IDs e informações estratégicas;

confira compartilhamento, retenção e uso para treinamento;

prefira uma base sintética quando não houver autorização formal.

Segundo a documentação do Gamma, a configuração padrão de espaços individuais permite o uso do conteúdo para melhorar recursos de IA, com opção de desativação. Em espaços Team e Business, o conteúdo fica excluído desse uso. Planos e controles podem mudar, então verifique a configuração atual antes de enviar qualquer material.
